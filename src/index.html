async function drawDashboard() { try { // Azureの裏側API（先ほど作ったプログラム）へデータを取りに行く const response = await fetch('/api/GetSheetData'); const csvText = await response.text(); const rows = csvText.split('\n').slice(1); const chartLabels = []; const chartData = []; rows.forEach(row => { const columns = row.split(','); if(columns.length >= 2) { chartLabels.push(columns[0].replace(/"/g, '').trim()); chartData.push(Number(columns[1].replace(/"/g, '').trim())); } }); const ctx = document.getElementById('myChart').getContext('2d'); new Chart(ctx, { type: 'bar', data: { labels: chartLabels, datasets: [{ label: 'スプレッドシートのデータ', data: chartData, backgroundColor: 'rgba(54, 162, 235, 0.6)', borderWidth: 1 }] } }); } catch (error) { console.error('データの取得に失敗しました:', error); } } drawDashboard();
